# Atharv Kakade — Portfolio

A responsive dark-modern personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `atharv-portfolio`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

The site uses Google Fonts from the web. All project, contact, education and skill details are based on the supplied resume. C programming, Generative AI, and the Tata Forage GenAI item have been excluded as requested.
